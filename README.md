# Kelvin Ikpeni Digital Studio

A world-class, full-stack personal portfolio and digital product showcase. Built from scratch using Node.js, Express.js, MongoDB, and Vanilla JavaScript.

## 🚀 Features
- **Premium UI:** Dark-first design with glassmorphism, CSS animations, and a custom mouse follower.
- **Dynamic Portfolio:** Project showcase with filtering, search, and case studies.
- **Admin Dashboard:** Secure JWT authentication to Create, Read, Update, and Delete projects.
- **Analytics:** View counters for project case studies.
- **Inbox System:** View, reply to, and manage contact form submissions directly from the dashboard.
- **Draft Preview:** Preview unpublished projects before making them live.
- **Security:** Helmet, Rate Limiting, Input Sanitization, and Secure Cookies.
- **Deployment:** Fully configured for Render.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Security:** Helmet, express-rate-limit, express-validator, bcryptjs, JWT
- **Deployment:** Render
